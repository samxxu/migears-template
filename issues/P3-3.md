# P3-3 — The `## section(...) ##` special case only recognises a single-line …

## Finding / 问题

- EN: The `## section(...) ##` special case only recognises a single-line quoted literal. With a newline in the name the regex misses and the whole expression degrades to `<?= $this->e(section('a\nb')) ?>`, i.e. a call to an undefined global `section()` at render time; `## section('x') . 'y' ##` degrades the same way.
- 中文: ## section(...) ## 特判只识别单行引号字面量。section 名含换行时正则不匹配，整个表达式退化为 <?= $this->e(section('a\nb')) ?>，渲染时调用未定义的全局函数 section()；## section('x') . 'y' ## 同样退化。
- Where / 位置: `src/TemplateCompiler.php:62-76`
- Verification / 验证: reproduced / 已实证
